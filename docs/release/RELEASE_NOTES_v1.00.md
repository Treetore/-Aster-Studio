# Aster Studio v1.00 发行说明

- 版本：**v1.00**（包版本 `1.0.0`）
- 日期：2026-11-22
- 平台：Windows 10/11 + NVIDIA（单机单任务）
- 许可：Apache-2.0；模型权重不随发行包分发

## 主要功能

- Web 工作台与桌面启动器（Aster Studio / Aster 启动器）；
- MiniMax H3 视频：文生视频、首尾帧、参考图、长片分段与拼接；
- Qwen-Image 2.1、MOSS-Image 文生图/图像编辑；
- 长片总时长设置（5–600s），按 124 帧/段自动换算分段；
- 自定义时长与宽高；主机模式自适应直出上限（低显存/标准/高配）；
- 任务优先级队列、项目/合集、提示词预设、通知 Webhook、基础中英切换；
- ComfyUI-Manager 模型市场同步（569 条），自动安装检测、许可/来源与断点下载；
- 首次启动向导、自检、主机模式、模型选择与下载；
- MCP / HTTP / 桥接接口、资源守卫、进程清理、日志轮转；
- 可选 AstrBot 插件（默认不安装）。

## 安装

1. 解压到任意可写目录；
2. 准备 ComfyUI（本项目不内置）；
3. 运行 `start_all.bat`；
4. 打开 `http://127.0.0.1:8190/`，按首次启动向导配置。

详见 `SETUP.md`。

## 已知限制

- 市场部分模型下载需要上游登录/许可确认；
- 队列为进程内队列，重启不保留；
- 前端尚未迁移组件框架；
- 完整表单级 i18n 待补；
- 模型识别依赖文件名与目录；
- H3 暂无原生视频参考生成，只有参考图/首尾帧。
