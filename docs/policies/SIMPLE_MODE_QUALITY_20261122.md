# 精简模式与质量参数修复（2026-11-22）

## 问题
Web 视频页默认 `steps=4` + 4-step Turbo LoRA + 608×352，而自动脚本用 8 步 / 720p，
导致网页生成的画面细节、稳定性明显低于自动生成。

## 修复
- 新增「精简模式 / 专业模式」切换，默认精简；
- 精简模式只保留：提示词、模式、参考图/@、时长、画质；
- 画质预设：
  - 标准：960×544，8 步，**无 LoRA**，optimize=max；
  - 高质量：1280×736，8 步，**无 LoRA**，optimize=max；
  - 快速：608×352，4 步，4-step Turbo；
- 专业模式保留全部原参数（分辨率、步数、LoRA、二采、高级参数等）；
- 默认专业参数也改为 720p / 8 步 / 无 LoRA；
- 后端支持 `lora_name="none"` 关闭 auto_lora 的默认 Turbo LoRA。

## 自动匹配
- <12s 直出；≥12s 自动分段；
- 720p >10s 自动上下文窗口 + 分块 VAE。
