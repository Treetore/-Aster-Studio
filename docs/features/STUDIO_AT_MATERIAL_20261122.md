# 视频提示词 @ 素材（2026-11-22）

## 用法

1. 在「创作视频」提示词框点 **@ 素材**，或直接输入 `@`；
2. 从弹出网格选择 `input/` 里的图片；
3. 提示词中出现 `@文件名`，生成时自动：
   - 把该文件加入 `ref_images`；
   - 模板从 t2v/fl2v 自动切到 `minimax_h3_r2v`；
   - 从提示词中移除 `@文件名`（模型只看到正文）。

## 接口

- `GET /api/assets`：列出 input 目录图片（名称/路径/mtime）；
- `/api/generate` 会解析 `@name`，仅当 input 下存在同名图片才生效；
- 上传文件名中的空格会替换为 `_`，避免 @token 截断。

## 示例

```
@char_girl.png 海边黄昏，少女回头看向镜头，镜头缓慢推进
```

等价于 r2v + ref_images=["char_girl.png"]，prompt="海边黄昏，少女回头看向镜头，镜头缓慢推进"。
